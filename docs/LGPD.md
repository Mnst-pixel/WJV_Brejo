# LGPD

Kairós applies privacy by design and data minimization. The system records purpose, category, legal basis, retention, operator, sharing, and origin for each personal-data class.

Implemented workflows must support authenticated export, correction where applicable, deletion or irreversible anonymization where legally permitted, retention holds, incident records, and auditable administrative execution. User A can never access User B's answers, files, notes, conversations, or history.

Canonical user and learning data lives in Django/PostgreSQL. WordPress contains no private learning profile. AI providers receive only the minimum scoped context and no reusable human administrator credentials.
